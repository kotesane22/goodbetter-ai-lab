# ikeP ポートフォリオサイト 要件定義 v1.0

## 目的
仕事依頼の獲得と作品販売への導線を50:50で。
「ikePって何者か」がファーストビュー30秒で伝わること。

## ページ構成
1. トップ：キャッチコピー＋イケピー＋主要導線
2. About：プロフィール、実績（SHIFT AI、生成AIパスポート等）
3. Works：作品ギャラリー（カテゴリフィルタ付き）
4. Shop：販売リンクカード集
   - ファミマプリント クリエイターズ
   - LINEスタンプ（LINE STORE）
   - Coconala
   ※サイト内決済は作らない。外部リンクのみ
5. Contact：X・note・お問い合わせ導線

## 技術要件
- 静的HTML/CSS/JS、フレームワーク不使用
- GitHub Pages公開前提（リポジトリ構成もこの前提で）
- 作品・販売リンクは data/works.json と data/shop.json に
  分離し、JSON追記だけで更新できる構造にする
- デザイントークン（色・フォント・余白・角丸・影）は
  css/tokens.css にCSS変数として完全分離
- レスポンシブ必須。スマホ閲覧を第一に設計
- OGP・favicon・meta記述込み

## デザイン方針
- ブランドカラー：ティール基調（イケピーの色）
- トーン：親しみやすさ×プロ感
- 禁止：ソシャゲ風テンプレ、意味のない装飾、
  均一に埋め尽くされた画面、ありがちなグラデヒーロー
- 余白で見せる。作品が主役、装飾は脇役

## 進め方
1. リポジトリ構成の提案 → 私の承認後に実装
2. まずトップとWorksを完成させ、確認を挟むこと
3. 作品データは仮データ3件で構造を作り、
   後から私が実データを流し込めるようにする

## 実装メモ（Claude向け・運用ルール）

### このディレクトリの位置づけ
- モノレポ `goodbetter-ai-lab` 内の1アプリ。パスは `apps/portfolio/`。
- 既存の `apps/diagnostic-tool`（Next.js製・研修診断ツール）とは独立。
- 本サイトはビルド不要の純粋な静的サイト（HTML/CSS/JS）。

### 更新運用（重要）
- 作品を増やす＝ `data/works.json` に1オブジェクト追記するだけ。
- 販売リンクを増やす＝ `data/shop.json` に1オブジェクト追記するだけ。
- HTML/JSには手を入れない設計を厳守する。
- デザイン変更は原則 `css/tokens.css` の変数だけで完結させる。

### 禁止事項（デザインガードレール）
- ソシャゲ風テンプレ、意味のない装飾、画面の均一な埋め尽くし、
  ありがちなグラデーションヒーローは作らない。
- 余白で見せる。作品が主役、装飾は脇役。
