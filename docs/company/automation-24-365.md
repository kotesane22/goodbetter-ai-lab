# 24時間365日 自動で働かせる仕組み

「自分が寝ている間も会社イケピが働く」を実現する方法は、大きく3つある。
おすすめは **① Routines(定期実行)** 。PCの電源を切っていてもクラウドで動く。

## ① Routines(Claude Codeの定期実行) — おすすめ

Claude Code(Web版・デスクトップアプリ)の **Routines** 機能で、
決まったスケジュールでClaudeをクラウド上で起動できる。自分のPCが不要。

- 公式ドキュメント: https://code.claude.com/docs/ja/scheduled-tasks
- 最小間隔は1時間。cron式(例: `0 6 * * *` = 毎朝6時)で指定
- 各実行はこのリポジトリを開いた新しいセッションとして動く
  → CLAUDE.mdとサブエージェントが自動で読み込まれ、「会社として」動く

### 会社イケピの推奨ルーティン構成(3本)

| ルーティン | スケジュール | プロンプト内容 |
|-----------|------------|--------------|
| 朝のネタ出し便 | 毎朝6時 | researcherで売れ筋テーマを調査し、企画案を docs/content/research/ にコミット |
| 昼の執筆便 | 毎日13時 | 未着手の企画からwriterが下書きを1本書き、reviewerがレビューして docs/content/drafts/ にコミット |
| 週次売上レポート | 毎週月曜9時 | analystがTips MCPで売上を取得・分析し、docs/content/sales/ にレポートをコミット |

ポイント: **自動化するのは「下書きまで」**。公開ボタンは社長が押す。
これで暴走リスクなく24時間体制が作れる。

## ② /loop(セッション内の繰り返し)

開いているセッションの中で「10分ごとに○○して」と繰り返させる機能。
短時間の見張り(ビルド待ち・デプロイ監視など)向き。
**セッションを閉じると止まる**ので、24時間365日の用途には不向き。

## ③ GitHub Actions(すでに一部導入済み)

このリポジトリは `main` へのpushでGitHub Pagesへ自動デプロイされる
(`.github/workflows/deploy-pages.yml`)。
定時実行(`on: schedule`)でClaude Code GitHub Actionを動かすこともできるが、
セットアップの手間があるので、まずはRoutinesで十分。

## 組み合わせの全体像

```
[Routines(クラウド定期実行)]
   ↓ 毎日決まった時間にこのリポジトリで起動
[CLAUDE.md + サブエージェント5部門]
   ↓ 調査→執筆→レビューを自動実行、結果をgitにコミット
[社長(あなた)]
   ↓ 通勤中などにGitHub/Claude Codeで下書きを確認・修正指示
[Tips MCP]
   → 承認したものだけ「これ公開して」の一言で公開
```
