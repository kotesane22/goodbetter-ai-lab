# 幼稚園から始める言語化の本

## 概要

このプロジェクトは「言語化」のスキルを、幼稚園レベルの超基礎から段階的に学べる本の原稿です。

「言語化」とは、頭の中にある考えや感情を、他の人に伝わる言葉に変換するスキルです。
仕事でも、人間関係でも、自己成長でも、すべての基盤になる力です。

## 対象読者

- 「自分の考えをうまく言葉にできない」と感じている人
- プレゼンや報告が苦手な社会人
- 書くことに苦手意識がある人
- 子どもに言語化を教えたい親・教育者

## コンセプト

「難しい言葉を使わずに、小さな子どもでも理解できるシンプルなルールから始める」
