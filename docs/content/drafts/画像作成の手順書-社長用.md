# 📷 画像作成の手順書(社長用)

初商品「現場で働く人のためのAI画像生成入門」を公開するために、
記事内のプロンプトを実際に動かして、画像を用意する手順です。

**やること: 下のプロンプトをコピペで実行 → できた画像を保存 → 私に送る(またはTips画面に貼る)**
スマホのChatGPTアプリだけで、全部で30分ほどです。

---

## ✅ 最低ライン(これだけでも公開できる)

### 画像①: 店頭POP(第6章のメイン実例)

ChatGPTアプリに、次の文をそのままコピペして送信してください。

```
カフェの店頭に貼るA4縦のPOP用画像を作ってください。
【被写体】マシュマロをのせた温かいココア。木のカウンターに置く。
【雰囲気】冬の午後、窓から柔らかい光が入る、ほっとする雰囲気。写真風。
【構図】上部3分の1は空や壁などシンプルな背景にして、
大きな文字を入れられる余白にしてください。
【形】縦長(A4)でお願いします。
```

- 出てきた画像が気に入らなければ、続けて「もっと明るく」「余白を広く」などと返信して直す
- 「これなら店に貼れる」と思えたら、その画像を保存

## 🎯 できれば欲しい(記事の説得力が上がる)

### 画像②: 最初の1枚(第4章)

```
カフェの店頭に貼るPOP用の画像を作ってください。
湯気の立つホットコーヒーのカップを、木のテーブルに置いた写真風の画像。
温かみのある朝の光。上の方に文字を入れるための余白を空けてください。
縦長(A4に印刷する想定)でお願いします。
```

### 画像③: 文字入れの例(第6章・方法A)

画像①か②が出たあと、続けてこう送る:

```
この画像の上部の余白に、以下の文字を入れてください。
・大きく「冬のあったかココア」
・その下に小さく「マシュマロトッピング +100円」
読みやすい太めの文字で、画像の雰囲気に合う色でお願いします。
```

※これは「AIは日本語が崩れることがある」という記事の説明の実例になります。
きれいに出ても、崩れても、どちらでも記事の教材になります(崩れた例はむしろ貴重)。

### 画像④(Midjourneyを使うなら): サムネイル用

記事のサムネイル(表紙)画像。Midjourneyかniji、なければChatGPTでもOK:

```
秋のキャンプ場のカフェ。木のカウンターに置かれた湯気の立つコーヒー。
朝の柔らかい光。写真風。上部に文字用の余白。縦長。
```
