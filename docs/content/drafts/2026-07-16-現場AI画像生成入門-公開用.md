先に結論を言います。

**デザインの勉強をしたことがなくても、AIを使えば「店に貼れるレベルのPOP・SNS画像」は作れます。しかも、最初の1枚は明日作れます。**

この記事は「AIで月○万円稼ぐ」という話ではありません。約束するのはひとつだけ。

> **あなたの明日の業務が、少し楽になること。**

- 手書きPOPに1時間かけていたのが、下絵をAIに任せて15分になる

こういう変化を、手順書レベルで具体的に書きました。読み終えた翌日、休憩時間にスマホかバックヤードのPCで1枚作ってみてください。そのための記事です。

## 第1章 自己紹介 — 私はデザイナーでもエンジニアでもない、現場の人間です

はじめまして。私は今、キャンプ場で働いています。場内のカフェの運営と、法人向けの食事提供が担当です。

その前は、スターバックスで働き、プリンスホテルでサービス業務をしていました。派遣ではフォークリフトに乗り、水道管を直し、アスファルトを舗装し、ゴーカートのサーキット場も作りました。約10年、ずっと「現場」です。累計で10万人くらいのお客様と接してきた計算になります。

つまり私は、AIの専門家ではありません。**「現場の仕事を回すためにAIを使っている当事者」** です。

今の職場では、**店頭のPOPをAI画像で作っています**。MidjourneyとChatGPTの両方を、場面によって使い分けています。さらに、カフェのフードロス対策にもAIを使っています。一人当たりの提供数量をAIで算出し、料理の提供タイミングを変えた結果、フードロス率はほぼゼロになりました。AIは「すごい技術」ではなく、私にとっては**ゴム手袋やラミネーターと同じ、現場の道具**です。

そしてもうひとつ。現場で「AIの入門書」を探したとき、困ったことがありました。世の中のAI画像生成の教材は、書き手がほぼ「AI副業のインフルエンサー」か「エンジニア・デザイナー」なんです。読んでいて、**シフトの合間に、油と洗剤の匂いがする手でスマホを触る人間のことは想定されていない**と感じました。

## 第2章 なぜ「現場の人」こそAI画像生成なのか

### 理由1: 現場の販促物は「速さと数」が命で、AIはそこが得意

店の掲示物は、締切が常に「今週末」です。桜が咲けば春フェア、雨が続けば雨の日サービス。デザイン会社に発注していたら間に合わないし、予算もない。だから現場では、手書きPOPやワープロ打ちの貼り紙が量産されます。

AI画像生成は、1枚あたり数十秒〜数分で画像を出します。100点の1枚を1週間かけて作る道具ではなく、**75点の1枚を15分で作る道具**。これは現場の要件そのものです。

### 理由2: 「何が伝わるか」を一番知っているのは現場のあなた

デザインの技術がなくても、あなたは「うちのお客様は何に反応するか」を毎日見ています。AIに絵を描く技術を任せられるようになった今、残る仕事は「何を描かせるか決めること」。それは現場感覚そのものです。ここが、外部のデザイナーやAIインフルエンサーに真似できない部分です。

### 理由3: 特別な機材も、若さも、パソコンスキルもいらない

この記事の手順は、スマホ1台でも実行できます。私の職場のバックヤードにも高性能PCなんてありません。「ITが苦手」は問題になりません。実際、必要な操作は**「日本語で文章を打って送信する」だけ**です。LINEが使えれば足ります。

### 一つだけ、先に正直に言っておくこと

AIは万能ではありません。特に苦手なのが、**画像の中の日本語の文字**です(第10章で対策を書きます)。また、料理写真をAIで作って「実物と違う」とお客様をがっかりさせたら本末転倒です(これも第10章)。**得意なことだけやらせて、苦手なことは人間が5分だけ手を貸す**。この分担がわかれば、AIは現場で一番働き者の後輩になります。

## 第4章 準備編 — 最初の30分でやること(まずはChatGPTだけでいい)

### 4-1. アカウントを作る(所要10分)

1. スマホのアプリストアで「ChatGPT」を検索し、**OpenAI公式のアプリ**をインストールする(似た名前の別アプリに注意。開発元が「OpenAI」であることを確認)
2. メールアドレスで登録(GoogleやAppleのアカウントでも可)
3. まずは**無料プランのままでOK**。課金は1枚も作らないうちからしなくていい


### 4-2. 最初の1枚を出してみる(所要5分)

アプリを開いて、メッセージ欄に次の文をそのまま打って送信してください。

```
カフェの店頭に貼るPOP用の画像を作ってください。
湯気の立つホットコーヒーのカップを、木のテーブルに置いた写真風の画像。
温かみのある朝の光。上の方に文字を入れるための余白を空けてください。
縦長(A4に印刷する想定)でお願いします。
```

数十秒待つと画像が出ます。**これでもう、あなたはAI画像生成ができる人です。** 特別な操作は最後までこれだけ、「日本語で頼んで送信」です。

### 4-3. 気に入らなかったら「会話で」直す(所要15分)

ChatGPTの最大の強みは、**続けて日本語で修正を頼める**ことです。出てきた画像に対して、そのまま返信してください。

- 「もう少し明るくしてください」
- 「カップを白ではなく赤にしてください」
- 「背景を屋外のウッドデッキにしてください」
- 「余白をもっと広く取ってください」

デザインソフトの使い方を覚える必要はありません。**「後輩に口頭で頼むように直させる」**のがAI画像生成の正しい使い方です。この30分で、道具は手に入りました。ここからは「何を頼むか」の質を上げていきます。

## 第5章 基本編 — 現場画像プロンプト「5つの型」

プロンプト(AIへの指示文)は、次の5つの要素を埋めるだけで安定します。私が現場で使っている型です。

| 要素 | 内容 | 例 |
|---|---|---|
| ① 用途 | 何に使う画像か | 「店頭POP用」「Instagram投稿用」 |
| ② 被写体 | 何を写すか | 「湯気の立つホットコーヒー」「焚き火とマシュマロ」 |
| ③ 雰囲気 | 季節・時間帯・トーン | 「秋の夕方、暖色系、落ち着いた雰囲気」 |
| ④ 構図・余白 | 文字スペースの指定 | 「上部3分の1に文字用の余白」 |
| ⑤ 形・サイズ | 縦横比・印刷/画面 | 「縦長、A4印刷用」「正方形、SNS用」 |

### 型に流し込んだ例文(コピペして単語を入れ替えて使ってください)

```
【① 用途】○○用の画像を作ってください。
【② 被写体】(メインに写したいもの)を中心に、
【③ 雰囲気】(季節)(時間帯)の(明るい/落ち着いた)雰囲気で。
【④ 構図】(上部/下部)に文字を入れる余白を空けてください。
【⑤ 形】(縦長/横長/正方形)でお願いします。
```

### 現場で効く3つのコツ

**コツ1: 「余白」を必ず指定する。** POPには必ず文字が載ります。余白の指定を忘れると、画面いっぱいに被写体が描かれ、文字の置き場がなくなります。私の体感では、これを指定するだけで「使える率」が大きく上がります。

**コツ2: 「写真風」か「イラスト風」かを最初に決める。** 同じコーヒーでも、写真風は「本格・大人向け」、イラスト風は「親しみ・ファミリー向け」に見えます。店の客層で選んでください。プロンプトに「写真風の画像」「手描き風の温かいイラスト」と一言入れるだけです。

**コツ3: 1回で完成させようとしない。** 1枚目は「たたき台」です。第4章のとおり、会話で2〜3回直して仕上げる。合計でも15分あれば足ります。逆に、プロンプトを1回で完璧にしようと悩む時間はムダです。現場の掃除と同じで、まず一度拭いてから汚れの残りを見る方が速い。

## 第6章 実践編① 店頭POPを作る(A4掲示物・完全手順)

一番出番が多い「A4に印刷して店頭・場内に貼るPOP」を、最初から最後まで通しでやります。想定は「カフェの新メニュー告知」です。あなたの商品に単語を入れ替えてください。

### 手順1: 素材画像をChatGPTで作る(10分)

```
カフェの店頭に貼るA4縦のPOP用画像を作ってください。
【被写体】マシュマロをのせた温かいココア。木のカウンターに置く。
【雰囲気】冬の午後、窓から柔らかい光が入る、ほっとする雰囲気。写真風。
【構図】上部3分の1は空や壁などシンプルな背景にして、
大きな文字を入れられる余白にしてください。
【形】縦長(A4)でお願いします。
```

出てきた画像を、第4章の要領で2〜3回修正して「これなら店に貼れる」まで持っていきます。

### 手順2: 文字を入れる(2つの方法)

**方法A: ChatGPTに文字ごと入れさせる(手軽だが要チェック)**

```
この画像の上部の余白に、以下の文字を入れてください。
・大きく「冬のあったかココア」
・その下に小さく「マシュマロトッピング +100円」
読みやすい太めの文字で、画像の雰囲気に合う色でお願いします。
```

**ただし、AIは日本語の文字が苦手です。** 一見きれいでも、よく見ると字が崩れていることがあります。**印刷前に、文字を1字ずつ指差し確認してください。** 崩れていたら「『あ』の字が崩れています。直してください」と返信して作り直させます。ただし、2〜3回直しても崩れが取れないことがあります。その場合は粘らず、次の方法Bに切り替えてください。その方が速いです。

**方法B: 文字はAIに入れさせず、自分で載せる(確実。私はこちらを推奨)**

AIには「文字なしの背景画像」だけ作らせて、文字は普段使っているソフト(WordやPowerPoint、スマホの画像編集アプリなど、職場で使い慣れたもの)で上から載せる方法です。文字化けが原理的に起きないので、**値段や日付など間違えられない情報はこちら**にしてください。


### 手順3: A4で印刷する(5分)

意外とつまずくのがここです。スマホで作った画像を紙にする方法は、主に2つあります。

1. **職場のプリンタで刷る**: 生成された画像を長押し(またはダウンロードボタン)でスマホに保存 → 職場のPCにメールや普段使っている連絡ツールで送り、いつもの方法でA4印刷
2. **コンビニのマルチコピー機で刷る**: 保存した画像を、コンビニ各社の印刷アプリ(またはネットワークプリントのWebサイト)に登録 → 店頭のコピー機に予約番号を入力してA4カラー印刷(1枚数十円)

※AI画像は、大きく引き伸ばすと粗く見えることがあります。**A4までなら実用上十分**です。ポスターなど大判の掲示物を作りたくなったら、第9章のMidjourneyの出番です。

### 手順4: 印刷して貼る前の最終チェック(5分)

- [ ] 文字の誤字・崩れはないか(指差し確認)
- [ ] **価格・日付・商品名は正しいか**(AI任せにした部分は特に)
- [ ] 料理・商品の画像が実物とかけ離れていないか(→第10章)
- [ ] 3歩離れて読めるか(POPは歩いている人に読ませるもの)

## 第7章 実践編② SNS告知画像を作る(Instagram/X)

### POPとの違いは2つだけ

1. **形が違う** — Instagramは正方形または縦長、Xは横長が基本。プロンプトの【⑤ 形】を変えるだけです
2. **文字は少なく** — SNSでは説明文はキャプション(投稿文)に書けます。画像内の文字は「ひとこと」だけの方が見栄えします

### プロンプト実例(Instagram向け・正方形)

```
Instagramの投稿用画像を作ってください。
【被写体】焚き火を囲むマグカップのコーヒー。手袋をした手が持っている。
【雰囲気】晩秋のキャンプ場の夕暮れ。オレンジ色の焚き火の光。写真風。
【構図】中央に被写体。文字は入れないでください。
【形】正方形でお願いします。
```

### 「写真がない日」の救世主として使う

SNS運用で一番つらいのは「今日載せる写真がない」日です。雨で客足が少ない日、仕込みに追われて撮影を忘れた日。そういう日に、**告知・お知らせ系の投稿(営業時間、イベント予告、雨の日サービス)をAI画像で埋める**という使い方が現場的には一番効きます。

ただし、**AIで作った画像を実際の商品・風景の写真であるかのように見せない**こと。「イメージ画像」とわかる使い方に留めるのが、お客様との信頼を守る線引きです(詳細は第10章)。

## 第8章 実践編③ メニュー・季節フェアのイメージ画像を作る

### メニュー表の「挿絵」に使う

メニュー表の商品写真そのものをAIにするのは推奨しません(実物と違う問題。第10章)。効くのは**「挿絵・背景・飾り」**です。

```
カフェのメニュー表に使う飾りのイラストを作ってください。
【被写体】コーヒー豆、カップ、木の葉を組み合わせた小さな飾りイラスト。
【雰囲気】手描き風、線は茶色、背景は白(メニューの紙に馴染むように)。
【構図】余白の多いシンプルな配置。
【形】横長でお願いします。
```

背景が白のイラストは、既存のメニュー表の隅に置くだけで「ちゃんと作った感」が出ます。

### 季節フェア・イベント告知のキービジュアル

フェアの告知は「まだ存在しない光景」を見せる仕事なので、実はAIが一番堂々と使える領域です。実物の写真がなくても嘘になりません。

```
キャンプ場の「秋の焚き火フェア」告知用の画像を作ってください。
【被写体】夜のキャンプ場、大きな焚き火、周りに人のシルエット、舞う火の粉。
【雰囲気】わくわくするけど落ち着いた、大人のアウトドアの雰囲気。写真風。
【構図】上部に告知文字用の余白。
【形】縦長でお願いします。
```


## 第9章 ステップアップ — Midjourney / Niji Journeyに進むと何が変わるか

### 進むべきタイミング

ChatGPTだけで、店のPOP・SNSは十分回ります。次の症状が出たら、Midjourneyを検討してください。

- ChatGPTの画像だと「あと一歩、雰囲気が足りない」と感じ始めた
- 看板・ポスターなど、大きく印刷する物を作りたくなった
- 毎週コンスタントに作るようになり、無料プランの枚数制限が業務の邪魔になった

### Midjourney — 「光と空気」が別物

Midjourneyは画像生成の専門サービスで、有料(最安プランで月額10ドル前後〜)です。私の実感では、**光の表現と質感**が強い。夕暮れの焚き火、朝靄に包まれたキャンプサイト、湯気——「空気が写っている」ような画像が出ます。

使い方の要点だけ書きます。

1. Midjourney公式サイトでアカウントを作り、プランを契約する
2. プロンプトは**英語が基本**です。ただし身構えなくて大丈夫。**日本語で考えた指示文をChatGPTに「Midjourney用の英語プロンプトにして」と頼めばいい**のです。使い慣れた道具に翻訳係をやらせる。これが現場流です

```
(ChatGPTへの頼み方の例)
以下の内容をMidjourney用の英語プロンプトにしてください。
「秋のキャンプ場のカフェ。木のカウンターに置かれた湯気の立つコーヒー。
朝の柔らかい光。写真風。上部に文字用の余白。縦長。」
```

3. 縦横比は、プロンプトの末尾に `--ar 3:4`(縦長)や `--ar 1:1`(正方形)と付けて指定します

ChatGPTに翻訳させると、たとえばこんなプロンプトが返ってきます(そのまま貼り付ければOK)。

```
autumn campsite cafe, steaming coffee cup on a wooden counter,
soft morning light, photorealistic, empty space at the top for text --ar 3:4
```

覚えておくと便利な指定は、この3つだけで十分です。

| 書き方 | 意味 | 現場での使いどころ |
|---|---|---|
| `--ar 3:4` / `--ar 1:1` / `--ar 16:9` | 縦横比(縦長/正方形/横長) | POPは縦長、Instagramは正方形、X・看板は横長 |
| `--no text` | 「文字を入れないで」 | 文字は自分で載せる方式(第6章・方法B)のときに必ず付ける |
| `--no people` | 「人物を入れないで」 | 実在スタッフと誤解される画像を避けたいとき |

生成されると4枚の候補が並ぶので、気に入った1枚を選んで高解像度化(アップスケール)する、というのが基本の流れです。同じ構図のまま微調整したいときは「バリエーション」を選ぶと、雰囲気を保ったまま別案が出ます。ここまで覚えれば、業務用途には十分です。

※機能・画面・料金は更新が速いため、本章の記載は2026年7月時点のものです。


### Niji Journey — イラスト・アニメ調ならこちら

Niji JourneyはMidjourneyの姉妹サービスで、**イラスト・アニメ調に特化**しています。Midjourneyのサブスクリプションで利用できます。

現場での使いどころは明確で、**「かわいい系」が正解の場面**。ファミリー向けイベントの告知、子ども向けメニュー、マスコット風のワンポイントイラスト。写真風のMidjourneyとイラスト風のNiji Journeyを場面で使い分けると、店の掲示物に幅が出ます。

頼み方はMidjourneyと同じで、ChatGPTに翻訳させてから貼り付けます。

```
(日本語で考える例)
「子ども向けの焼きマシュマロ体験の告知イラスト。たき火とマシュマロ。
絵本のようなやさしいタッチ。明るい色。上に文字用の余白。縦長。」
```

イラスト調は写真調より文字入れ(手描き風フォント)との相性がよく、第6章・方法Bの「文字は自分で載せる」やり方がそのまま活きます。


### 費用対効果の考え方(現場の算数)

月額10ドル前後(約1,500円)は、POPの外注1枚分より安いことがほとんどです。判断基準はシンプルに、**「月に2枚以上、掲示物やSNS画像を作るか?」**。作るなら元は取れる、というのが私の考えです。ただし契約は自腹ではなく、**職場の経費にできないか先に相談する**こと。業務で使う道具なのですから。

## 第10章 現場で使うときの注意 — 文字化け・著作権・「実物と違う」問題

道具の使い方より大事な章です。現場でAI画像を「安心して」使い続けるためのルールを4つ。

### ルール1: 文字は必ず人間が最終確認する

繰り返しになりますが、AIは画像内の日本語文字を崩すことがあります。**価格・日付・アレルギー表示など、間違えたら実害が出る情報は、AIに文字を描かせず自分で載せる**(第6章の方法B)。これを職場の決まりにしてください。

### ルール2: 料理・商品の「本物のふり」をさせない

AIで作った料理画像は、実物より美しくなりがちです。それをメニューの商品写真として使うと、**お客様は「写真と違う」と感じます**。景品表示法の優良誤認(実際より著しく良く見せる表示)にあたるリスクもゼロではありません。現場の線引きはこうです。

- **OK**: 雰囲気画像・背景・挿絵・イベント告知(まだ存在しない光景)・「※イメージです」と明記した使用
- **避ける**: 実在の商品の写真として使うこと。実物の料理は実物を撮るのが一番です

約10年、サービスの現場でお客様と向き合ってきた人間として言いますが、販促物で一瞬得をしても、がっかりさせた瞬間に信頼ごと失います。AIはお客様の期待値を「正しく上げる」ために使ってください。

### ルール3: 有名キャラクター・作家・実在人物に寄せない

「○○(有名アニメ)風で」「芸能人の○○が座っている絵」といった指示は、著作権・パブリシティ権のトラブルの元です。業務利用では絶対に避けてください。スタイルの指定は「手描き風」「水彩風」「レトロなポスター風」のような**一般的な言葉**で行えば十分伝わります。

### ルール4: 商用利用の条件と職場のルールを確認する

- ChatGPT・Midjourneyとも、規約上、生成画像の商用利用は基本的に認められています(プラン・条件により扱いが異なる場合があるため、**契約時に最新の利用規約を確認**してください)
- **Midjourneyには重要な条件があります**: 年商100万ドル(約1.5億円)を超える企業に勤めていて業務で使う場合、**Proプラン以上の契約が規約で求められています**。チェーン店・ホテル・大手運営のレジャー施設で働く人はここに該当しやすいので、会社の経費で契約する際にプラン選びごと相談してください
- チェーン店・ホテルなど本部がある職場では、**掲示物のルールやブランドガイドラインが先**です。AI画像を店頭に出す前に、上長に一言通しておく。これはAIの問題ではなく、現場の仁義の問題です
