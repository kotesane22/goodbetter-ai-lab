# content — コンテンツ制作の作業場

コンテンツ販売(Tips / note / Brain / Udemy)とSNS・発信に関する成果物をここに蓄積する。

## フォルダ構成

- `research/` — 市場調査・競合分析(リサーチ部)
- `drafts/` — 記事・教材の下書き(コンテンツ制作部)
- `marketing/` — タイトル案・販売ページ文・SNS告知文(マーケティング部)
- `reviews/` — 公開前レビュー結果(品質管理部)
- `sales/` — 売上レポート(売上分析部)

## 素材について

社長の経験・実績・過去にやってきたことのメモは `research/` に
「素材メモ」として置いておくと、各エージェントが執筆時に参照する。
