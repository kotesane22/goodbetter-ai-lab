## 答え方

- チャットに箇条書きでも、音声入力で話したままでもOK。順番もバラバラでいい
- 覚えていないこと・なかったことは「覚えてない」「ない」でOK(**それも記事の正確さに効く**)
- お客様・同僚・職場が特定される情報は記事には書かない(こちらでぼかす)

## 第1便 — フードロス5問(最優先。これだけで2商品が同時に動く)

3本目の成立条件であり、2本目の第8章(A-4)も同時に解消する。

| # | 質問 | 埋める形 |
|---|------|---------|
| F-1 | AIには何を渡して、何を出させていますか? | 入力:【 】/ 出力:【 】/ ツール:【 】 |
| F-2 | 提供タイミングは「いつ出していたのを、いつに変えた」? | 変更前:【 】→ 変更後:【 】/ きっかけ:【 】 |
| F-3 | AIを使う前は、どうやって数量を決めていましたか? | (前任者の数字のまま / 人数×決まった数 / 勘 など) |
| F-4 | 最初にAIに聞いたとき、うまくいかなかったことは? | (的外れな数字 / 聞き方が悪かった / 記録がなかった など) |
| F-5 | 予測が外れた日は、現場でどう逃がしましたか? | (まかないに回す / 翌日に転用 / 別メニューで補う など) |

※ 数字(ロス率・食数など)は、覚えている範囲だけで構わない。なければ記事に数字は書かない。
