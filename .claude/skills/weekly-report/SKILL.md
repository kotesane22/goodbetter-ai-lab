# 週次売上レポート

毎週月曜の朝に、会社イケピの数字を3分で把握できる状態にする。

## 手順

### Step 1: データ取得

- Tips MCPのツールで売上・販売数・閲覧データを取得する
- **MCP未接続の場合**: `docs/content/sales/` の過去記録と、社長から貼り付けてもらった
  データで代替。それもなければ「データなし」として、代わりに販売準備状況(下書き・
  レビューの進捗)をレポートする(空振りで終わらせない)

### Step 2: 分析(analystエージェントに委任)

- 商品別・期間別の傾向(何が・いつ・どれだけ売れたか、前週比)
- 無料部分の閲覧数と購入数の比率(わかる場合)— タイトル・サムネの改善余地の判定材料

### Step 3: レポート作成

`docs/content/sales/YYYY-MM-DD-週次レポート.md` に保存してコミット。構成:

1. **3行サマリー**: 今週の売上 / 前週比 / 一番のニュース
2. **数字**: 商品別の販売数・売上(表形式、データがある範囲で)
3. **続ける・やめる・試すの3点提案**: それぞれ具体的なアクションまで落とす
   (例:「サムネ文言をB案からC案に変える」— 「頑張る」は禁止)
4. **社長への相談事項**: 価格変更・セール等、お金に関わる提案はここに書く(実行はしない)

### Step 4: 報告

- 3行サマリー+提案をチャットで社長に報告する

## 禁止事項

- 価格変更・クーポン発行・商品取り下げの実行(提案まで。実行は社長の承認後)
- データにない数字の推定値をあたかも実数のように書くこと(推定は「推定」と明記)
